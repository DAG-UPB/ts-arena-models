# TS-Models

Welcome to the **TS-Models** repository! This project is a core component of the **TS-Arena** ecosystem.

**Main project:** [https://github.com/DAG-UPB/ts-arena](https://github.com/DAG-UPB/ts-arena)

## Call for Feedback

We have implemented these models to the best of our knowledge. However, we highly value input from the original model authors or the community. If you spot any issues with the implementation or have suggestions for better hyperparameters/configurations, please open an issue or a pull request!

## Getting Started

- **Taking part with your own model (Open Track):** register in the [console](https://console.ts-arena.live) and submit forecasts through the API. The [participation guide](https://github.com/DAG-UPB/ts-arena/tree/main/ts-arena-participation_example) in the main repository explains how.
- **Adding a model to the Reference Track:** every model in this repository is part of the Reference Track. Follow the [contribution guide](CONTRIBUTING.md). It covers which models qualify, how a model service is built, tested and run, and what the pull request needs.
